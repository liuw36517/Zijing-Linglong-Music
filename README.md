# ♜ 紫荆玲珑 Zijing Linglong

一个基于 Web 技术制作的本地音乐播放器。

无需服务器，
无需账号，
音乐文件全部保存在用户自己的浏览器中。

---

## ✨ 功能特点

### 🎵 本地音乐播放

支持：

- MP3
- WAV
- FLAC
- OGG


直接上传音乐文件即可播放。


---

## 💿 音乐库

使用浏览器：
保存音乐数据。


特点：

- 本地存储
- 无需上传服务器
- 刷新网页不会丢失
